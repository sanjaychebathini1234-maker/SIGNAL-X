# SIGNAL-X Schematics

This directory contains circuit diagrams and wiring documentation for the
SIGNAL-X hardware architecture.

## Planned Documentation

- Main controller wiring
- RF receiver interface
- RF transmitter interface
- OLED display connection
- MicroSD interface
- User-control connections
- Power distribution
- GPIO allocation

## Status

The schematics in this directory represent the proposed hardware design.
They will be updated when the corresponding hardware is implemented and
verified.

Diagrams marked as conceptual should not be interpreted as verified
hardware measurements.
