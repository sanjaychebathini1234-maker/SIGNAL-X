# SIGNAL-X Experiments

This directory contains experimental procedures, observations, measurements
and test results collected during the development of SIGNAL-X.

## Planned Experiments

- RF signal detection
- Receiver sensitivity testing
- Signal capture testing
- Signal characterization
- Storage and retrieval testing
- Controlled replay testing
- Range testing
- Power consumption testing
- Reliability testing

## Experiment Records

Each experiment will document:

- Objective
- Hardware configuration
- Test conditions
- Procedure
- Observations
- Measurements
- Results
- Conclusions

Experimental results will be added as the physical prototype is developed.
